🔧 Firebase Setup

This app needs a free Firebase Realtime Database to sync players in real time. Follow these steps once — it takes about 5 minutes.

Step 1 — Create a Firebase Project

Go to console.firebase.google.com and sign in with your Google account.

Click Add project, give it a name (e.g. "GameRoom"), skip Google Analytics if asked, and click Create project.

Step 2 — Create a Realtime Database

In the left sidebar, click Build → Realtime Database, then click Create Database.

Choose any location (US is fine). When asked about security rules, choose Start in test mode (we'll keep it simple). Click Enable.

Step 3 — Get your config keys

Click the gear icon ⚙️ next to Project Overview → Project settings. Scroll down to Your apps and click the </> (web) icon. Register the app (any nickname), then copy the config shown. It looks like:

const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "yourproject.firebaseapp.com", databaseURL: "https://yourproject-default-rtdb.firebaseio.com", projectId: "yourproject", ... };

Paste each value into the fields below:

Step 4 — Security Rules (recommended)

In the Realtime Database section, click the Rules tab and replace the content with this (validates data structure, prevents abuse):

{ "rules": { "rooms": { "$roomId": { ".read": true, ".write": true, "players": { "$playerId": { ".validate": "newData.hasChildren(['name']) && newData.child('name').isString() && newData.child('name').val().length > 0 && newData.child('name').val().length <= 20" } }, "nudges": { "$playerId": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 200" } }, "nudgeSentTotals": { "$senderId": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 5000" } } } } } }

Click Publish.

Welcome to SideKick
A simple turn-taking app for board games, card games, and table-top game nights. No more arguing about whose turn it is — SideKick keeps track for you.
🏠
Create a Room
Tap Create a Room and set up your name, color, and avatar. Pick a turn mode — Classic Turns passes left, right, or both ways. Speed Round lets players race to tap in.
Step 1 → Step 2 → Step 3
📱
Share the Room Code
A 4-letter code is generated. Share it — or let players scan the QR code — so they can join from their own phone. Everyone picks their own name, color, and avatar.
⏭️
Take Turns
The host taps Start Game. Each player sees their own screen with a big Pass Turn button. Tap it when you're done — the next player's screen lights up. The active player's name glows so everyone knows whose turn it is.
⚙️
Extra Features
Turn on Nudge to poke slow players. Add Timers for turns, rounds, or the whole game. Enable Awards for fun achievements. Try different Themes from the settings icon. Everything is optional — use what you like.
📲
Add to Your Home Screen
Install SideKick like a real app for the best experience. It loads faster, looks better, and gets its own icon.
iPhone / iPad (Safari):
Tap the Share button ⬆ at the bottom, then scroll down and tap "Add to Home Screen".
Android (Chrome):
Tap the ⋮ menu in the top-right, then tap "Add to Home screen" or "Install app".
🎉
Ready to Play?
That's it! Create a room or join one to get started. SideKick keeps the game flowing so you can focus on the fun.
